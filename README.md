# Currency Converter

A simple, mobile-friendly React app to convert between Liberian Dollar (LRD), Ghanaian Cedi (GHS), and US Dollar (USD).  
Fetches live exchange rates from a free API and updates instantly. Designed with a clean, minimal UI for quick market conversions.

## Features

- Real-time currency conversion between USD, GHS, and LRD  
- Uses a free public API for live exchange rates  
- Mobile-friendly and responsive design  
- Simple, clean UI for quick use  
- Built with React functional components and hooks

## Usage
Enter any amount in USD, GHS, or LRD and the other two currencies will update instantly.
